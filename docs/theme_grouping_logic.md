# Thematic Analysis - Grouping Logic

## Overview
Reviews were classified into 6 business-relevant themes based on keyword matching.

## Theme Definitions

### 1. Account Access & Login Issues
**Keywords:** login, password, otp, access, sign, fingerprint, biometric, authentication, verification, code
**Business relevance:** Users facing authentication problems, login failures, OTP delays

### 2. Transaction Performance
**Keywords:** slow, fast, transfer, payment, speed, loading, timeout, delay, processing, transaction
**Business relevance:** Speed of money transfers, bill payments, transaction processing time

### 3. UI & Design
**Keywords:** ui, interface, design, user friendly, easy, navigation, layout, cluttered, modern, intuitive
**Business relevance:** App usability, visual design, ease of navigation

### 4. Customer Support
**Keywords:** support, help, customer, service, assistance, call, agent, complaint, response, chat
**Business relevance:** Quality of customer service, complaint resolution

### 5. Crashes & Bugs
**Keywords:** crash, bug, error, freeze, close, fix, issue, problem, glitch, not working
**Business relevance:** Technical stability, app reliability

### 6. Feature Requests
**Keywords:** feature, update, improve, add, new, function, enhancement, missing, would like, suggest
**Business relevance:** Desired functionality, competitive advantage opportunities

## Assignment Method
- Case-insensitive keyword matching
- First matching theme wins
- Reviews with no keyword matches assigned "Other"

## Results
| Theme | Description |
|-------|-------------|
| Account Access & Login Issues | Authentication problems |
| Transaction Performance | Speed and reliability of transactions |
| UI & Design | App interface and usability |
| Customer Support | Support quality and responsiveness |
| Crashes & Bugs | Technical stability |
| Feature Requests | Missing functionality |
